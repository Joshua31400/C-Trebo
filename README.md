<h2 id="introduction" align="center">📖 Introduction</h2>

> **Gestionnaire de tâches collaboratif**.
> 
Trebo est une application conçue pour permettre aux équipes d'organiser leur travail en tableaux, listes et cartes.

L'enjeu principal de ce projet réside dans la mise en place d'une architecture logicielle robuste et maintenable.

L'application se distingue par son interactivité, offrant notamment un drag & drop fluide et une collaboration instantanée entre les membres grâce à une synchronisation en temps réel.

---

<h2 id="features" align="center">⭐ Features</h2>

### 👤 User Features
- 📚 Build and manage your personal dashboard
  - Column/ cards
  - Labels
  - Comments
- 💑🏼 Invite team mates
- 🏆 Track archive

### 🔐 Authentications
- 📧 Traditional email/password login
- 🔒 Secure password hashing (bcrypt)
- 🛡️ Protected routes with middleware

<h2 id="how-to-install" align="center">🚀 How to install?</h2>

### Récupération du projet.
1.  ```bash
    git clone https://github.com/Joshua31400/C-Trebo.git
    ```
2.  ```bash
    cd C-Trebo
    ```

### Lancement du projet (API).    
3.  ```bash
    cd TreboApi
    ```
4.  ```bash
    dotnet run --urls "http://0.0.0.0:5214"
    ```

### Lancement du projet (WEB).
5. ```bash
   cd TreboWeb
   ```
6. ```bash
   node server.js
   ```
